- `assets/favicon/` — browser tab, Apple touch icon and PWA manifest

## Dashboard mockup

`mockups/sca-dashboard.html` was supplied by the project owner. It is a
self-contained visual mockup with embedded IBM Plex Sans Arabic font subsets,
Lucide icons, compiled Tailwind CSS, hand-built charts and fictional demo data.
It does not connect to the real SCA GMS database.

## Fonts

The landing loads these fonts from Google Fonts under the SIL Open Font License:

- Reem Kufi (landing display type)
- IBM Plex Sans Arabic
- IBM Plex Mono

The mockup embeds its own IBM Plex Sans Arabic subsets, so it works offline.

## Front-end

Plain HTML, CSS and JavaScript. No 3D runtime, framework or external JavaScript
library is used by the landing page.
